# Retail Store Sales & Profitability Analysis

##  Project Overview

This project analyzes retail store sales data using **Microsoft Excel** to understand sales performance, profitability, product and category performance, customer orders, returns, delivery performance, geographic performance, and payment behavior.

The project follows a complete business analytics workflow:

**Business Understanding → Data Understanding → Data Validation → Analysis → KPI Development → Statistical Analysis → Dashboard → Business Insights → Recommendations**

---

##  Business Problem

The business has transactional sales data but needs a clear understanding of:

- Sales and profit performance
- Product and category profitability
- Customer orders and returns
- Delivery performance
- Geographic performance
- Payment behavior
- Monthly sales trends

The objective is to convert the raw transactional data into meaningful business insights that can support better decision-making.

---

##  Business Objectives

- Analyze total sales, cost and profit
- Measure overall profitability
- Identify high- and low-performing categories
- Analyze product performance
- Evaluate order returns
- Analyze delivery performance
- Compare geographic performance
- Analyze payment methods
- Identify important business trends
- Build an interactive Excel dashboard
- Provide actionable business recommendations
